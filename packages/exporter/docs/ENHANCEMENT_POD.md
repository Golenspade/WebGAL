# WebGAL Exporter 增强计划 POD

最后更新：2025-10-27
负责人：Golenspade（实施） / Augment Agent（评审）
目标版本：0.2.x（渐进式交付）

## 1. 背景与问题
WebGAL Exporter 已经具备“用浏览器录制画面 → 抽帧 → FFmpeg 编码 →（可选）音轨混合”的通路，但对 WebGAL 全量特性（尤其是音频与交互）的兼容不完整，导致：
- 语音（vocal）、音效（SE）、视频音轨未纳入混音；
- BGM 的淡入/淡出、音量变化、循环等未还原；
- 选择/输入无法自动化；
- 对话推进/标题进入无自动化；
- 场景完成时间被误判（无演出≠场景结束）。

## 2. 目标（G）
- G1 可靠完成全流程导出：从标题页进入、自动推进、直到脚本自然结束（或显式 end）。
- G2 声音完整还原：BGM、vocal、SE、视频音轨，含起止点、音量曲线、淡入淡出、循环（常见模式）。
- G3 交互自动化：choose / getUserInput 可按脚本或配置确定性执行。
- G4 具备可验证性：为每个增强点补齐单元测试；提供可复现实例与验证清单。
- G5 开发者体验：提供清晰的开发文档、运行指南、PR 检查清单。

## 3. 非目标（NG）
- NG1 不追求像素级逐帧同步 Web Audio 的分析精度；
- NG2 不实现复杂动态混音（实时 ducking、EQ 等）；
- NG3 不做重型端到端（E2E）CI 运行（可留到后续）。

## 4. 关键方案概述
- 浏览器侧注入：
  - 修正并增强 DOM 观察器与事件监听，覆盖 BGM / vocal / SE / video 音轨。
  - 注入自动化交互：进入标题、自动推进（模拟空格/回车）、选择与输入的正确选择器。
  - 改善“完成判定”：使用“空闲窗口 + 状态信号（end 或回到标题）”策略。
- Node 侧重建：
  - AudioReconstruction 识别多类音频事件，生成轨道与淡入淡出/音量变化信息；
  - FFmpegMixer 支持必要滤镜（adelay/volume/afade/atrim/aloop），并合入视频音轨；
  - 提供可离线调试的 timeline.json 与可读的滤镜日志。
- 测试：
  - 以 Vitest 为主的单元测试（Node 与 JSDOM），覆盖解析、选择器、滤镜生成、时长推导等。

## 5. 成功标准（S）
- S1 在给定样例剧本上，导出的视频与浏览器内播放的一致性通过人工抽检（画面与声音事件相位误差<200ms）。
- S2 关键音频类型（BGM、vocal、SE、视频音轨）均入轨，淡入/淡出与音量变化可感知；
- S3 任意存在选择/输入的脚本，在提供 branch-script 后可自动走通；
- S4 100% 新增能力有对应单测，覆盖率（语义性）>80%（对核心模块）。

## 6. 里程碑（M）与时间盒
- M1（P0）执行流打通：标题进入、自动推进、完成判定修正、选择器修复（~2d）
- M2（P0）音频覆盖第一批：vocal/SE/视频音轨事件捕获与混音（~3d）
- M3（P1）BGM 增强：淡入/淡出、音量变化、切换/停止、基础 loop（~3d）
- M4（P1）CLI 覆盖：textSpeed/autoSpeed 注入与验证（~1d）
- M5（P1）文档与样例：Demo 场景、操作手册、验证清单（~1d）

## 7. 风险与对策
- R1 Playwright/FFmpeg 环境差异 → 文档化安装前置、错误报告增强；
- R2 DOM 结构变动 → 选择器加容错（多选择器并联）、在注入脚本中集中声明；
- R3 时基误差（录制 vs 事件）→ 采用时间戳统一原点，允许±200ms 容错；
- R4 循环音频复杂度 → 先支持“直到下一 BGM 或场景结束”的常见模型。

## 8. 评审与验收
- 每个里程碑完成后提交 PR：
  - 必含：变更说明、迁移/兼容性说明、单测结果、样例导出视频/日志。
- Reviewer 核对：
  - 单测覆盖核心路径；
  - 样例剧本导出的视频/音频与预期一致；
  - 失败时可复现（含命令与输入）。

## 9. 附录：当前缺口一览（用于拆解）
- 交互：
  - 标题点击进入（.title__enter-game-target）；
  - 自动推进（空格/回车 或直接触发 nextSentence）；
  - choose 选择器错误（.Choose_item）；
  - getUserInput 选择器错误（#user-input + .button）。
- 音频：
  - 未监听 #currentVocal；
  - SE 使用动态 <audio> 且不入 DOM，需从 perform 数据/生命周期推断；
  - 未监听 <video> 音轨；
  - BGM 未记录 enter/volume/停止/切换/loop 信息；
  - 音量变化曲线未记录（AudioContainer 的渐变）。
- 完成判定：
  - 以“无演出”为完成条件会误判；需加入空闲窗口与状态信号。
